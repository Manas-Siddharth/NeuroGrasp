# Dataset Setup & Specification Guide

## 1. Dataset Distinctions

NeuroGrasp distinguishes between two dataset implementations:

### A. Simulated Jacquard-Style Dataset (`data/sample_dataset/`)
- **Type**: Synthetically Generated Prototype Data
- **Sample Count**: 200 RGB images ($1024 \times 1024$ resolution) and corresponding `_grasps.txt` files.
- **Generation Method**: Programmatically rendered geometric primitives (rectangles, ellipses, L-shapes, T-shapes) generated by `data/create_sample_dataset.py`.
- **Purpose**: Local hardware verification, unit testing, GPU training pipeline validation, and real-time visualization demo out-of-the-box.

### B. Full Real-World Jacquard Dataset (`data/jacquard/`)
- **Type**: Real Synthetic CAD & Physics Simulation Benchmark Dataset (Depierre et al., ICRA 2018).
- **Sample Count**: 54,000+ RGB-D images, 11,000 unique CAD objects, 11+ million annotated grasps.
- **Official Portal**: [https://jacquard.liris.cnrs.fr/database.php](https://jacquard.liris.cnrs.fr/database.php)
- **Purpose**: Production benchmark training for real-world robotic deployment.

## 3. Jacquard Annotation Format

Each object image (e.g. `1_1_RGB.png`) has a corresponding text file `1_1_grasps.txt` containing one or more valid grasp lines:

```text
x;y;theta;opening;jaws_size
```

- **`x`** (float): Center X-coordinate in pixels.
- **`y`** (float): Center Y-coordinate in pixels.
- **`theta`** (float): Grasp angle in degrees relative to horizontal axis.
- **`opening`** (float): Gripper opening width ($w$) in pixels.
- **`jaws_size`** (float): Gripper jaw height ($h$) in pixels.

---

## 4. Setup Instructions for Full Jacquard Benchmark

To train NeuroGrasp on the full 54,000-image real-world Jacquard benchmark:

1. Download dataset archives from [https://jacquard.liris.cnrs.fr/database.php](https://jacquard.liris.cnrs.fr/database.php).
2. Extract the archive into `data/jacquard/`.
3. Update `config.yaml`:
   ```yaml
   data:
     data_dir: "data/jacquard"
   ```
4. Run `python -m src.train` to train on the full benchmark dataset.
